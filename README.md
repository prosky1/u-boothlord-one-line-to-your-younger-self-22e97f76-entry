## What it does

`main.ts` writes exactly one line to `/output/entry.txt` — the single line
sent back to a younger self, no explanation, no second sentence:

> She will marry the man who sent the text you keep rewriting.

60 characters, one line, one sentence. The program validates the line
(length, single line, single sentence) before writing, then reads the
file back and verifies it matches byte for byte before exiting.
